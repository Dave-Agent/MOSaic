# scripts/sim

Routine tests: `c64sim.py` (the API: `symbol`, `run`, `rom_byte`), `symbols.py` (Kick `.sym` / `.vs` lookup), `run_tests.py` (runs `tools/tests/test_*.py`), `example_test.py` (a project-free example you can run as it is).
Run from a project: `python3 <skill>/scripts/sim/run_tests.py --root . [--phase 1]`. See `references/testing.md`.
