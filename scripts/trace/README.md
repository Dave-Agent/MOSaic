# scripts/trace

`c64trace.c` is the project-neutral 6510 simulator (build: `gcc -O2 -o c64trace c64trace.c`; the scripts build it into `$BUILD_DIR/trace/c64trace` themselves). Its options are documented in the comment at the top of the file.
`c64env.py` is the shared setup (project.config keys, build overlay, symbol lookup). `selftest.py` runs the tracer's self-tests. `entry_points.py` writes entry points and code/data ranges from seeded runs. The generic guide is `references/testing.md`.

`sample_report.py VAR... --run [--keep-run PREFIX] -- TRACER ARGS` (or `--smp FILE --ranges FILE`) prints, per variable (a label of the source, a scoped name such as `Namespace.member` / `Routine.local` taken from the build's `.sym` file (`--sym FILE`, else `TRACE_SYM(_P1)`, the newest `.sym` under `SRC_DIR/build` or `BUILD_DIR`, then `VICE_SYMBOLS`), or `$ADDR`, `NAME:N` for N bytes), the frames where it changes and its values, run-length: the
rung-3 observation of `phase1_method.md` in one command. `--keep-run PREFIX` keeps the scratch run's coverage files (`PREFIX.hits` ...) instead of deleting them, which is what `hit_counts.py` reads. `hit_counts.py ADDR|LABEL... --runs PREFIX...` (scoped names resolve the same way, `--sym FILE`) prints how often instructions at those addresses started in each run (which side of a branch ran). The input can
change during a run: `--joy1-at` / `--joy2-at` / `--keymat-at FRAME=VALUE` (repeatable), see the top of `c64trace.c`; `selftest.py` proves it with a tiny program.

**Keys from a hand-off image.** The tracer models CIA 1 as the machine does: a keyboard column is selected only by an output pin of port A driven low, and a port read gives the pins (`(PRA | ~DDRA) & joystick`, so joystick 2 reads whatever DDRA is). A hand-off image does not carry the CIA registers, so a run starts with DDRA = 0 and no column could be selected. When `--keymat` / `--keymat-at` is given and no `--init` line writes `$DC02`, the tracer therefore starts with DDRA = PRA = `$FF` (what the KERNAL's reset leaves; it prints a note), so no `--init` workaround is needed; an explicit `dc02` line is respected. If the program itself leaves no column selected when it reads `$DC01`, a WARNING at the end says the keys were never visible. `selftest.py` proves all three with a tiny program that never writes DDRA.
